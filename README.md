## Synopsis

[Spock.js](https://github.com/1pizzateam/Spock.js) is an open source mathematics library written in TypeScript.
Vectors, matrices, trigonometry, bezier curves, lerp, random distribution and so on.

- No dependency
- Very lightweight
- Thoroughly tested
- Works in browsers and Node.js

## Motivation

The main purpose of this library is to provide a comprehensive tool for all projects involving mathematics functions.

## Installation

```bash
$ npm install @1pizzateam/spockjs
```
